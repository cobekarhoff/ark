# Reviewer rubric

Grade one PR or MR body. Answer each item pass or fail with one quoted line of evidence.

1. **Problem first.** The first lines say what was wrong or missing for a reader, before any description of the change.
2. **Nothing restated.** No sentence repeats the title, the diff, a heading, or another sentence.
3. **What is not done.** Open gaps, unproven criteria and deferred work are listed, or the body says there are none.
4. **Risk and revert.** The body says what can break, how far it reaches and how to undo it. A one-way door names its recovery.
5. **Runnable validation.** Each verify step is a command a reviewer can copy, with the result to expect.
6. **Numbers with bounds.** Every count, time or size says what it is measured against, or gives its limit.
