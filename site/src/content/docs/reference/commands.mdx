This command-line interface (CLI) reference is generated on every build by executing
`bun cli/ark.ts --help`. It includes all commands, including `test` and `launch`,
not just the commands exposed as typed tools. Edit the help in `cli/ark.ts` and run
`bun run docs:build` to update this page; do not hand-edit a second command list.

<CommandReference />

Commands that own ledger evidence must be called directly: `advance` cannot forge
gate answers, tests, worktree creation or merge request outcomes. See
[implementation details](/reference/implementation/) for the ownership and attribution rules.
