Lifecycle

Amber states wait for you. Every other state runs by itself, under a round budget. The ark command keeps the transition table, so a run cannot reach building before you approve the plan.

Three shapes of a run

Same lifecycle, three workspaces. The diagram shows what Ark builds in the run folder and what lands at the end.

The run folder

Everything a run did is a file under ~/.ark/projects/<project>/runs/<run>/. The event log is the record; the rest is derived or written by an agent. These are from run 2026-11-05-ARK-311-1, shortened.
